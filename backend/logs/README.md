# SpeakFlow Logging Architecture

This directory holds persistent application and testing logs:

1. **`speakflow.log`**: 
   - Primary operational log generated by `main.py` via `RotatingFileHandler`.
   - Rotates automatically at 10 MB with up to 5 historical backup files (`speakflow.log.1`, etc.).
   - Records API requests, AI evaluator payloads, model latencies, and state transitions.

2. **`error.log`**:
   - Filtered error log capturing only `ERROR` and `CRITICAL` severity events.
   - Rotates automatically at 5 MB with up to 3 historical backup files.

3. **`acceptance_suite.log`**:
   - Audit trail generated by the End-to-End Acceptance Validation Suite (`e2e_acceptance_validation.py`).
   - Confirms database persistence, telemetry alignment, and 3-layer dashboard contracts across all 4 rounds.
